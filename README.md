# За край — интерактивный сериал

Веб-платформа для показа интерактивного сериала-антологии «За край». Четыре серии по 20 минут, две точки выбора в каждой серии, три исхода на каждую точку (A / B / таймер истёк).

---

## 📖 Что это такое

Пользователь смотрит видео, в определённые моменты оно встаёт на паузу, появляются две кликабельные области. Зритель выбирает одну — проигрывается короткая вставка (реакция героя), затем автоматически начинается следующая сцена.

Если зритель не успевает выбрать за 10 секунд — играется отдельная вставка «бездействия» и история продолжается по сценарию.

### 3️⃣ Логотипы и иконки сайта

**Где хранится:** `frontend/images/`. Раздаётся сервером как статика по пути `/images/...`.

| Имя файла | Что это | Размер / формат | Обязателен? |
|---|---|---|---|
| `logo.svg` | Логотип сериала (для главной) | SVG, до 300 КБ | Нет (без него — белый текст) |
| `brandbar.svg` | Логотипы продакшна и спонсоров | SVG, до 300 КБ, горизонтальный | Нет (без него — пустая плашка) |
| `favicon.png` | Иконка вкладки в браузере | PNG, 64×64 или 128×128 | Нет (можно убрать `<link>` в HTML) |
| `icon-192.png` | PWA-иконка для Android / iOS | PNG, 192×192 | Нет (нужна для установки PWA) |
| `icon-512.png` | PWA-иконка (крупная) | PNG, 512×512 | Нет |
| `frame1.jpg` … `frame6.jpg` | Резервные обложки / кадры | JPG, 1280×720 | Нет (используются только как фолбэк) |

**Как ссылаться в HTML:**

```html
<img src="/images/logo.svg" alt="За край">
```

**Важно:** SVG-файлы должны иметь `viewBox` и не содержать внешних ссылок на шрифты. Если логотип использует специфический шрифт — текст лучше перевести в кривые.

## 🔧 Ключевые поля JSON

### Сцена

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный ID сцены |
| `type` | enum | `start` / `ordinary` / `final` |
| `video` | string | URL или имя файла |
| `pause_at` | number | Секунда, где встаёт пауза |
| `choice_timeout` | number | Секунды до NO_CHOICE (по умолчанию 10) |
| `choices` | array | Варианты выбора |
| `no_choice` | object | Что при бездействии |
| `next` | string | ID следующей сцены |

### Область (`area`)

Все значения — **проценты**, 0–100:

```json
{ "x": 10, "y": 55, "width": 35, "height": 22 }
```

## **🚀 Инструкция по развертыванию сериала на сайте**

В этом документе описана пошаговая стратегия размещения интерактивного сериала на виртуальном сервере (VPS) от Reg.ru с использованием панели управления FastPanel. Мы отказались от CDN и S3 в пользу хранения видеофайлов напрямую на сервере, так как это проще в настройке, а Reg.ru не тарифицирует исходящий трафик.

🏗 Архитектура:

Сервер (VPS): Reg.ru (Ubuntu 24.04)

Приложения (можно заказать сразу на рег.ру и миновать Этап 2): FastPanel

Хранилище: Локальная папка server/uploads/ на сервере

Домен: купить на рег.ру (до 200 рублей в год)

Этап 1. Заказ VPS/VDS сервера на Reg.ru
Перейдите в панель управления Reg.cloud.

Создайте сервер со следующими параметрами:

ОС: Ubuntu 24.04 LTS.

Конфигурация: 1 vCPU, 2 ГБ RAM, 40 ГБ NVMe — важно для хранения видео.

Сеть: Обязательно добавьте 1 публичный IP-адрес.

Облачный роутер: НЕ подключайте (лишние расходы).

Дождитесь создания и сохраните IP-адрес, логин root и пароль (они придут на почту).

Этап 2. Установка FastPanel
Подключитесь к серверу по SSH из терминала (или через встроенную консоль Reg.ru):

bash
ssh root@ВАШ_IP_АДРЕС
Установите FastPanel одной командой (официальный скрипт):

bash
wget https://repo.fastpanel.direct/install_fastpanel.sh -O - | bash -
После завершения установки скрипт выведет ссылку для входа, логин и пароль. Зайдите в FastPanel по ссылке (обычно вида https://ВАШ_IP:8888).

Смените пароль по умолчанию в целях безопасности.

Этап 3. Настройка окружения и создание сайта
В FastPanel перейдите в «Настройки» → «Приложения». Найдите Node.js и нажмите «Установить» (рекомендуется версия LTS). Там же проверьте, что установлен PM2 (менеджер процессов).

Перейдите в раздел «Сайты» → «Создать сайт».

Имя сайта: ваш домен (например, za-kray.ru).

Движок (CMS): выберите Node.js.

Пользователь: создайте нового пользователя (например, zaykrai) или оставьте системного.

Нажмите «Создать».

Этап 4. Интеграция кода из GitHub
В карточке созданного сайта в FastPanel перейдите на вкладку «Бэкенд» (или «Node.js»).

Настройте параметры запуска:

Рабочая папка: путь к папке server (обычно /var/www/ВАШ_ПОЛЬЗОВАТЕЛЬ/data/www/ВАШ_ДОМЕН/server).

Команда запуска: npm start.

Версия Node.js: выберите ту, что установили (LTS).

Включите бэкенд (тумблер «Включено»).

Вернитесь на вкладку сайта и откройте Терминал (или подключитесь по SSH под пользователем сайта).

Клонируйте код из GitHub:

cd /var/www/ВАШ_ПОЛЬЗОВАТЕЛЬ/data/www/ВАШ_ДОМЕН/server
git clone https://github.com/breakskyprod/za_kray.git .
npm install
Создайте файл .env в папке server через файловый менеджер FastPanel или в терминале со следующим содержанием:

SERIES_FILE=series_v2.json
STATS_KEY=ваш_супер_секретный_ключ_для_статистики (придумать самим)
PORT=3000
Перезапустите процесс Node.js. В панели FastPanel нажмите кнопку «Перезапустить» (Restart) рядом с вашим сайтом.

Этап 5. Загрузка видеофайлов (Локально на сервер)
Так как мы храним видео на сервере, нам нужно загрузить все 36 файлов (в 4 разрешениях) прямо в папку uploads.

В FastPanel перейдите в «Файловый менеджер».

Откройте папку вашего сайта: /var/www/ВАШ_ПОЛЬЗОВАТЕЛЬ/data/www/ВАШ_ДОМЕН/server/uploads/.

Загрузите сюда все подготовленные видеофайлы (ep1_s1.mp4, ep1_s1_720.mp4, ep1_s1_1080.mp4 и т.д.), а также аудиофайл choice_ambient.mp3.

Внимание: Файловый менеджер FastPanel отлично справляется с большими файлами. Можно загружать их архивами (zip) и распаковывать прямо на сервере, чтобы сэкономить время.

Проверьте права доступа к файлам (они должны быть доступны для чтения пользователю, под которым работает Node.js).


Этап 5.1. Подготовка и конвертация видеофайлов (FFmpeg)
Чтобы не загружать с ноутбука 4 версии каждого файла (это долго), мы загрузили только исходники в 1080p, а перекодирование поручим серверу.

1. Установите FFmpeg на сервер:

sudo apt update && sudo apt install ffmpeg -y
2. Загрузите исходники:
Через файловый менеджер FastPanel загрузите все 36 исходных видеофайлов (в 1080p) в папку server/uploads/.

3. Создайте скрипт конвертации:
В терминале перейдите в папку uploads:

cd /var/www/ВАШ_ПОЛЬЗОВАТЕЛЬ/data/www/ВАШ_ДОМЕН/server/uploads/
nano transcode.sh
Вставьте в файл transcode.sh следующий код:

#!/bin/bash

for f in *.mp4; do
    # 1. Пропускаем файлы, которые УЖЕ являются результатом конвертации
    # (чтобы не конвертировать файлы с тегами _1080, _720 и т.д.)
    if [[ "$f" == *_1080.mp4 || "$f" == *_720.mp4 || "$f" == *_480.mp4 || "$f" == *_360.mp4 ]]; then
        continue
    fi

    base="${f%.mp4}"
    
    # 2. Проверяем, а не сконвертировали ли мы уже ЭТОТ файл?
    # Если версия 720p уже существует, значит, мы этот файл уже обработали.
    if [ -f "${base}_720.mp4" ]; then
        echo "Файл $f уже сконвертирован, пропускаем."
        continue
    fi

    echo "========================================="
    echo "Начинаю обработку: $f"

    # 3. Создаем копию исходника как 1080p (если плеер запросит 1080p)
    cp "$f" "${base}_1080.mp4"
    echo "-> 1080p готов (копия)"

    # 4. Делаем 720p
    ffmpeg -y -i "$f" -vf "scale=1280:-2" -c:v libx264 -b:v 2500k -c:a aac -b:a 128k -movflags faststart "${base}_720.mp4"
    echo "-> 720p готов"

    # 5. Делаем 480p
    ffmpeg -y -i "$f" -vf "scale=854:-2" -c:v libx264 -b:v 1200k -c:a aac -b:a 96k -movflags faststart "${base}_480.mp4"
    echo "-> 480p готов"

    # 6. Делаем 360p
    ffmpeg -y -i "$f" -vf "scale=640:-2" -c:v libx264 -b:v 800k -c:a aac -b:a 96k -movflags faststart "${base}_360.mp4"
    echo "-> 360p готов"
    
    echo "Файл $f успешно обработан!"
done

echo "========================================="

4. Запустите конвертацию в фоне:

chmod +x transcode.sh
nohup bash transcode.sh > transcode.log 2>&1 &

5. Проверка прогресса:
Можно закрыть терминал, процесс будет идти в фоне. Чтобы проверить статус, выполните "tail -f transcode.log". Когда скрипт завершится, в папке uploads появятся файлы с суффиксами _1080, _720, _480, _360.

Этап 6. Домен и SSL (HTTPS)
В панели вашего доменного регистратора (Reg.ru) привяжите домен к серверу:

Создайте A-запись: za-kray.ru -> ВАШ_IP_АДРЕС.

В FastPanel перейдите в раздел «SSL-сертификаты».

Нажмите «Создать» → выберите Let's Encrypt (Бесплатно).

Укажите ваш домен и привяжите его к сайту. FastPanel автоматически выпустит сертификат и настроит перенаправление с HTTP на HTTPS.

Включите галочку «Форсировать HTTPS».
