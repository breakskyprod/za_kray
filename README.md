# За край — интерактивный сериал

Веб-платформа для показа интерактивного сериала-антологии «За край». Четыре серии по 20 минут, две точки выбора в каждой серии, три исхода на каждую точку (A / B / таймер истёк).

**Живой проект:** https://za-kray.onrender.com

---

## 📖 Что это такое

Пользователь смотрит видео, в определённые моменты оно встаёт на паузу, появляются две кликабельные области. Зритель выбирает одну — проигрывается короткая вставка (реакция героя), затем автоматически начинается следующая сцена.

Если зритель не успевает выбрать за 10 секунд — играется отдельная вставка «бездействия» и история продолжается по сценарию.

---

## 🏗 Архитектура

```
Пользователь → CDN → S3 (видео)
             ↓
         Node.js сервер (Render / Selectel)
             ↓
         HTML / CSS / JS
```

**Стек:**
- **Бэкенд:** Node.js + Express
- **Фронтенд:** чистый HTML + CSS + JavaScript (без фреймворков)
- **Данные:** JSON-файлы (без БД)
- **Видео:** S3-хранилище + CDN
- **Хостинг:** Render (текущий) / Selectel (планируемый)

## 🚀 Быстрый старт (локально)

1. Установите Node.js (версия 18+): https://nodejs.org
2. Откройте терминал в папке `server`:
   ```bash
   cd server
   npm install
   npm run dev
   ```
3. Откройте http://localhost:3000

**На Windows PowerShell:** если `npm run dev` не работает, попробуйте `npm start`.

## 🎬 Как добавить новую серию

### 1. Снять видео

Понадобится **9 файлов** на одну серию:

**Основные сцены:**
- `epN_s1.mp4` — первая сцена, до первого выбора
- `epN_s2.mp4` — вторая сцена, между выборами
- `epN_credits.mp4` — финальные титры

**Вставки после выбора (по 3 на каждую точку):**
- `epN_s1_A.mp4`, `epN_s1_B.mp4`, `epN_s1_NC.mp4` — после первого выбора
- `epN_s2_A.mp4`, `epN_s2_B.mp4`, `epN_s2_NC.mp4` — после второго выбора

**NC** = No Choice, вставка если зритель не выбрал за 10 секунд.

### 2. Загрузить видео на S3

В бакет `zaykrai-video` (или ваш) через панель Selectel / VK Cloud.

**Проверьте CORS-политику бакета:**
```json
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["Range"],
    "ExposeHeaders": ["Content-Length", "Content-Range"],
    "MaxAgeSeconds": 3600
  }
]
```

### 3. Добавить серию в `series_v2.json`

Скопируйте блок из существующего сезона и поменяйте ID / названия / ссылки:

```json
{
  "id": 5,
  "episode_number": 5,
  "title": "Название серии",
  "cover": "https://ваш-cdn.com/covers/ep5_cover.jpg",
  "scenes": [
    {
      "id": "ep5_scene1",
      "type": "ordinary",
      "video": "https://ваш-cdn.com/ep5_s1.mp4",
      "pause_at": 480,
      "choice_timeout": 10,
      "choices": [
        {
          "id": "A",
          "label": "Первый выбор",
          "area": { "x": 10, "y": 55, "width": 35, "height": 22 },
          "after_choice": { "video": "https://ваш-cdn.com/ep5_s1_A.mp4" }
        },
        {
          "id": "B",
          "label": "Второй выбор",
          "area": { "x": 55, "y": 55, "width": 35, "height": 22 },
          "after_choice": { "video": "https://ваш-cdn.com/ep5_s1_B.mp4" }
        }
      ],
      "no_choice": {
        "after_choice": { "video": "https://ваш-cdn.com/ep5_s1_NC.mp4" }
      },
      "next": "ep5_scene2"
    },
    {
      "id": "ep5_scene2",
      "type": "ordinary",
      "video": "https://ваш-cdn.com/ep5_s2.mp4",
      "pause_at": 480,
      "choice_timeout": 10,
      "choices": [],
      "no_choice": {},
      "next": "ep5_credits"
    },
    {
      "id": "ep5_credits",
      "type": "final",
      "video": "https://ваш-cdn.com/ep5_credits.mp4"
    }
  ]
}
```

### 4. Сохранить и задеплоить

```bash
git add server/data/series_v2.json
git commit -m "Add episode 5"
git push
```

Render задеплоит автоматически.

## 🔧 Ключевые поля JSON

### Сцена

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный ID сцены (например, `ep1_scene1`) |
| `type` | enum | `start` / `ordinary` / `final` |
| `video` | string | URL или имя файла |
| `pause_at` | number | Секунда, где встаёт пауза и появляются кнопки |
| `choice_timeout` | number | Секунды до NO_CHOICE (по умолчанию 10) |
| `choices` | array | Варианты выбора |
| `no_choice` | object | Что происходит при бездействии |
| `next` | string | ID следующей сцены |

### Выбор (`choices[]`)

| Поле | Описание |
|---|---|
| `id` | `A` / `B` — условный идентификатор |
| `label` | Подпись (используется только в debug) |
| `area` | Координаты кликабельной области в % |
| `after_choice.video` | Видео-вставка после выбора |

### Область (`area`)

Все значения — **проценты от контейнера видео**, диапазон 0–100:

```json
{ "x": 10, "y": 55, "width": 35, "height": 22 }
```

- `x` — от левого края
- `y` — от верхнего
- `width` — ширина
- `height` — высота

**Совет:** чтобы понять, где размещать — откройте видео в плеере, поставьте на паузу, откройте F12 и «прикиньте» проценты. Или временно поставьте `x: 0, y: 0, width: 100, height: 100` — область займёт весь экран, увидите, где она находится.

## 📊 Статистика

### Публичный счётчик зрителей

```
GET /api/stats/public
```

Возвращает число уникальных зрителей — показывается на главной в блоке «О фильме».

### Полная статистика (по ключу)

```
GET /api/stats?key=ВАШ_КЛЮЧ
```

Ответ:
```json
{
  "total": 128,
  "unique": 47,
  "lastUpdated": "2026-10-16T18:32:11.000Z"
}
```

### CSV-экспорт

```
GET /api/stats/csv?key=ВАШ_КЛЮЧ
```

Скачивает CSV с полным списком зрителей. Полезно для отчётности.

**Ключ** задаётся в переменной окружения `STATS_KEY` на Render.

## 🧪 Debug-панель

Откройте плеер с параметром `?debug=1`:

```
https://za-kray.onrender.com/player_v2.html?episodeId=1&debug=1
```

Появится панель 🐞 в правом верхнем углу. Что можно делать:
- Смотреть текущую сцену, время и состояние
- **Jump to scene** — прыгнуть в любую сцену
- **RESET STATE** — сбросить прогресс
- **NO CHOICE** — принудительно вызвать NO_CHOICE

**Панель видна только при `?debug=1`** — обычный зритель её не увидит.

## 🎨 Как менять дизайн

### Цвета

Все цвета вынесены в CSS-переменные в начале `frontend/styles.css` и `frontend/player_v2.css`:

```css
:root {
    --accent-1: #4A9EFF;    /* основной акцент */
    --accent-2: #A45CFF;    /* второй акцент */
    --bg-dark: #0b0b1a;     /* фон */
    --bg-panel: #1a1a3e;    /* панели */
    --text-muted: #8a92a5;  /* второстепенный текст */
}
```

Поменяйте значения — обновится весь сайт.

### Логотип

Положите файл `logo.svg` в `frontend/images/`. Если файла нет — показывается белый текст «За край».

### Плашка с логотипами

Положите `brandbar.svg` в `frontend/images/` — появится тонкая плашка сверху.

## ❓ Частые проблемы

**«Cannot GET /»**
Сервер не находит `frontend/index.html`. Проверьте, что папка `frontend` лежит на том же уровне, что и `server`.

**Видео не воспроизводится**
- Проверьте, что файл загружен на S3.
- Откройте ссылку из JSON напрямую в браузере. Если 404 — файла нет.
- Проверьте CORS в настройках бакета.

**Сервер падает после правки JSON**
Проверьте JSON на валидность: https://jsonlint.com. Чаще всего — лишняя или пропущенная запятая.

**Прогресс не сохраняется между устройствами**
Локально — да, через `localStorage`. На сервере — через `states.json` по `viewer_id`.
