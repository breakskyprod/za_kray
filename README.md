# Интерактивные сериалы – финальный прототип

## Установка и запуск
1. Установите Node.js и PostgreSQL.
2. Создайте БД и выполните `create_tables.sql`.
3. В папке `server` создайте `.env` с вашими данными.
4. Установите зависимости: `npm install`
5. Запустите: `npm start`
6. Откройте http://localhost:3000

## Тестовый вход админа
- Логин: `admin`
- Пароль: `admin123`

## Структура
- `/` – главная страница сериала
- `/player.html?episodeId=1` – плеер
- `/admin-login.html` – вход админа
- `/admin.html` – панель управления (заглушка)
