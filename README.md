# За край — интерактивный сериал

Веб-платформа для показа интерактивного сериала-антологии «За край». Четыре серии по 20 минут, две точки выбора в каждой серии, три исхода на каждую точку (A / B / таймер истёк).

**Живой проект:** https://za-kray.onrender.com

---

## 📖 Что это такое

Пользователь смотрит видео, в определённые моменты оно встаёт на паузу, появляются две кликабельные области. Зритель выбирает одну — проигрывается короткая вставка (реакция героя), затем автоматически начинается следующая сцена.

Если зритель не успевает выбрать за 10 секунд — играется отдельная вставка «бездействия» и история продолжается по сценарию.

---

## 🏗 Архитектура

```
Пользователь → CDN → S3 (видео)
             ↓
         Node.js сервер (Render / Selectel)
             ↓
         HTML / CSS / JS
```

**Стек:**
- **Бэкенд:** Node.js + Express
- **Фронтенд:** чистый HTML + CSS + JavaScript (без фреймворков)
- **Данные:** JSON-файлы (без БД)
- **Видео:** S3-хранилище + CDN
- **Хостинг:** Render (текущий) / Selectel (планируемый)

### 3️⃣ Логотипы и иконки сайта

**Где хранится:** `frontend/images/`. Раздаётся сервером как статика по пути `/images/...`.

| Имя файла | Что это | Размер / формат | Обязателен? |
|---|---|---|---|
| `logo.svg` | Логотип сериала (для главной) | SVG, до 300 КБ | Нет (без него — белый текст) |
| `brandbar.svg` | Логотипы продакшна и спонсоров | SVG, до 300 КБ, горизонтальный | Нет (без него — пустая плашка) |
| `favicon.png` | Иконка вкладки в браузере | PNG, 64×64 или 128×128 | Нет (можно убрать `<link>` в HTML) |
| `icon-192.png` | PWA-иконка для Android / iOS | PNG, 192×192 | Нет (нужна для установки PWA) |
| `icon-512.png` | PWA-иконка (крупная) | PNG, 512×512 | Нет |
| `frame1.jpg` … `frame6.jpg` | Резервные обложки / кадры | JPG, 1280×720 | Нет (используются только как фолбэк) |

**Как ссылаться в HTML:**

```html
<img src="/images/logo.svg" alt="За край">
```

**Важно:** SVG-файлы должны иметь `viewBox` и не содержать внешних ссылок на шрифты. Если логотип использует специфический шрифт — текст лучше перевести в кривые.

### 5️⃣ Трейлер

**Где хранится:** GitHub Releases (тег `videos`).

**URL:** `https://github.com/breakskyprod/za_kray/releases/download/videos/trailer.mp4`

**Как отдаётся клиенту:** через прокси на сервере (`/trailer-proxy.mp4`), чтобы браузер не пытался скачать файл.

**Ссылка в `series_v2.json`:**

```json
"trailer": "/trailer-proxy.mp4"
```

Если переезжаете на S3 — залейте трейлер туда и укажите полный CDN-URL. Прокси тогда не нужен.

## 🚀 Быстрый старт (локально)

1. Установите Node.js (версия 18+): https://nodejs.org
2. Откройте терминал в папке `server`:
   ```bash
   cd server
   npm install
   npm run dev
   ```
3. Откройте http://localhost:3000

**На Windows PowerShell:** если `npm run dev` не работает, попробуйте `npm start`.

## 🎬 Как добавить новую серию

### 1. Снять видео (9 файлов)

**Основные сцены:**
- `epN_s1.mp4` — до первого выбора
- `epN_s2.mp4` — между выборами
- `epN_credits.mp4` — титры

**Вставки:**
- `epN_s1_A.mp4`, `epN_s1_B.mp4`, `epN_s1_NC.mp4`
- `epN_s2_A.mp4`, `epN_s2_B.mp4`, `epN_s2_NC.mp4`

### 2. Загрузить на S3

В бакет через панель Selectel / VK Cloud.

Проверьте CORS-политику бакета:

```json
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["Range"],
    "ExposeHeaders": ["Content-Length", "Content-Range"],
    "MaxAgeSeconds": 3600
  }
]
```

### 3. Добавить серию в `series_v2.json`

```json
{
  "id": 5,
  "episode_number": 5,
  "title": "Название",
  "cover": "https://cdn.example.com/ep5_cover.jpg",
  "scenes": [
    {
      "id": "ep5_scene1",
      "type": "ordinary",
      "video": "https://cdn.example.com/ep5_s1.mp4",
      "pause_at": 480,
      "choice_timeout": 10,
      "choices": [
        {
          "id": "A",
          "label": "Первый выбор",
          "area": { "x": 10, "y": 55, "width": 35, "height": 22 },
          "after_choice": { "video": "https://cdn.example.com/ep5_s1_A.mp4" }
        },
        {
          "id": "B",
          "label": "Второй выбор",
          "area": { "x": 55, "y": 55, "width": 35, "height": 22 },
          "after_choice": { "video": "https://cdn.example.com/ep5_s1_B.mp4" }
        }
      ],
      "no_choice": {
        "after_choice": { "video": "https://cdn.example.com/ep5_s1_NC.mp4" }
      },
      "next": "ep5_scene2"
    },
    {
      "id": "ep5_scene2",
      "type": "ordinary",
      "video": "https://cdn.example.com/ep5_s2.mp4",
      "pause_at": 480,
      "choice_timeout": 10,
      "choices": [],
      "no_choice": {},
      "next": "ep5_credits"
    },
    {
      "id": "ep5_credits",
      "type": "final",
      "video": "https://cdn.example.com/ep5_credits.mp4"
    }
  ]
}
```

### 4. Задеплоить

```bash
git add server/data/series_v2.json
git commit -m "Add episode 5"
git push
```

## 🔧 Ключевые поля JSON

### Сцена

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный ID сцены |
| `type` | enum | `start` / `ordinary` / `final` |
| `video` | string | URL или имя файла |
| `pause_at` | number | Секунда, где встаёт пауза |
| `choice_timeout` | number | Секунды до NO_CHOICE (по умолчанию 10) |
| `choices` | array | Варианты выбора |
| `no_choice` | object | Что при бездействии |
| `next` | string | ID следующей сцены |

### Область (`area`)

Все значения — **проценты**, 0–100:

```json
{ "x": 10, "y": 55, "width": 35, "height": 22 }
```

## ❓ Частые проблемы

**«Cannot GET /»** — проверьте, что папка `frontend` на том же уровне, что и `server`.

**Видео не воспроизводится:**
- Откройте ссылку из JSON напрямую — если 404, файла нет.
- Проверьте CORS в настройках S3-бакета.

**Сервер падает после правки JSON** — проверьте через https://jsonlint.com.
